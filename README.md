### 🔗 Live Demo
**Check out the live website here:** [https://mern-portfolio-notes.vercel.app/](https://mern-portfolio-notes.vercel.app/)

---

## ✨ Features
* **Personal Portfolio:** Clean, responsive UI showcasing projects, skills, and contact information.
* **Notes Management:** Create, Read, Update, and Delete (CRUD) functionality for personal notes.
* **RESTful API:** Robust backend architecture handling data requests.
* **Fast Build Tooling:** Lightning-fast frontend development utilizing Vite.

## 🛠️ Tech Stack
* **Frontend:** React.js (Bootstrapped with Vite)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas (Cloud-hosted)
* **Deployment:** Vercel (Frontend), Render (Backend)

## 📂 Folder Structure
The repository is structured into two main directories:
* `/client` - Contains the React/Vite frontend code.
* `/server` - Contains the Node.js/Express backend code.
